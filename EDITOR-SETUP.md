# Paul Today editor setup

This website is prepared for Pages CMS.

Once the repository and publishing connection are active, the owner can sign in at https://app.pagescms.org and edit:

- homepage text and Facebook link
- profile photo and image descriptions
- website colors
- About section
- portfolio entries
- videos, Reel links, thumbnails, introductions, and full stories

Saving in the editor publishes the updated content to the existing Cloudflare Pages project through the included workflow.
